# Tooling provenance

The .config build/test files and root tooling configuration were generated by
@grafana/create-plugin 7.11.0 in the existing local-dashboard-panel workspace.
They are reused here with that workspace's Grafana 13.2.2 dependency lockfile.
See https://github.com/grafana/plugin-tools and its Apache-2.0 license.
No Flow plugin implementation was copied. Project licensing remains undecided;
third-party rights and dependency notices are unaffected.

The generated tooling license text is retained in LICENSE.tooling.
