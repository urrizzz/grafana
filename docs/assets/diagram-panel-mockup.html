Interface Map

Interactive mockup / fictional data
One Grafana panel would contain this entire diagram. Place router cards and compact traffic displays wherever you need them.
This is a standalone concept preview, not built-in Canvas or a running Grafana plugin. The separate component wireframe remains the design reference.

Element settings

Select an element to configure it. Drag a router card or the grip above a traffic display.

  • Incoming
  • Outgoing
  • Historical outage

Traffic plots start at 120 × 70. Hover for time and IN/OUT values. Drag the corner of a selected traffic display to resize its graph. Scroll the diagram when zoomed in.

The proposed workflow
Add a router, add a traffic display, choose its router and interface, then place it on the diagram. Connections follow router movement. No chart scripts are exposed to the dashboard author.
What this mockup demonstrates
Free placement, independent element settings, graph resize, hover, editing/view modes, and local layout saving. Metric values and status are fixed scenarios. Router selection and interface names demonstrate configuration only; there are no live queries.
