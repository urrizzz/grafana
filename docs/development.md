## Commands and local runtime

Use Node 24, npm and Docker Compose. On this Windows workspace add `C:\Codex\tools\node` to PATH
and use `C:\Codex\tools\node\npm.cmd` when necessary. Run commands as Yuri for EFS access.

| Command | Purpose |
| --- | --- |
| `npm ci` | Install the checked-in lockfile; package lifecycle scripts disabled by .npmrc |
| `npm run check` | Typecheck, lint, unit checks, production build |
| `npm run dev` | Watch and rebuild plugin output |
| `npm run server` | Start isolated Grafana 13.2.2 at localhost:3001 |
| `npm run e2e` | Test actual plugin loading in the provisioned dashboard; start server first |
| `npm run server:stop` | Remove the disposable development container |
| `npm run package` | Create unsigned development ZIP/checksums under ignored artifacts/; requires Python |
| `python -m unittest discover -s dev -p "test_*.py"` | Validate mock metrics |

Build before starting Grafana. For browser tests install Chromium with `npx playwright install chromium`;
on this workspace reuse browsers with `PLAYWRIGHT_BROWSERS_PATH=C:\Codex\tools\playwright`.
The container is limited to 1 GiB/one CPU and bound to loopback. It does not mount existing Grafana data.
Its anonymous administrator access and unsigned-plugin allowance are development-only configuration.
The original layout dashboard is preserved. A separate [M2 preview](http://localhost:3001/d/network-map-data-dev)
uses provisioned Grafana TestData frames; see [M2 validation](m2-validation.md). Regenerate its fixture JSON
with `python dev/generate_frame_demo.py`. Actual VictoriaMetrics integration remains for M5.
Default plugin preinstallation/updates are disabled in this isolated instance. GOMEMLIMIT is 300 MiB within
the 1 GiB container limit after a test instance with default background plugins was OOM-killed.

CI runs checks, mock-data tests and the Grafana browser smoke test. The manual package workflow only uploads
unsigned artifacts; it creates no public release and uses no signing secret. Release automation will be
added once identity, license, publishing route and implementation are ready.
