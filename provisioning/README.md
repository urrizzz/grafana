# Local development provisioning

The original dashboard displays the M1 layout editor, without a data source or real metrics.
Open the panel menu > Edit, then Load fixture layout on an empty diagram. Save through Grafana; UI updates are enabled.
Use dev/Start-Review.ps1 to build and start/restart on either PC. Open http://localhost:3001/d/interface-map-dev.
Port 3000 and the existing Grafana data directory are not used by this Compose project.
Anonymous admin is for this loopback-bound development instance only.
New instances persist Grafana state in the Compose named data volume. Never delete it or use compose down -v.
The Yuri PC's existing container may predate this volume; the shared launcher restarts it without recreation.
Stop/start the instance with docker compose stop / docker compose start. Export saved dashboards before changing provisioning.

M2 adds datasources/testdata.yaml and dashboards/data-preview.json under a separate dashboard UID.
They use built-in TestData raw frames with a fixed historical range, generated by dev/generate_frame_demo.py.
No production endpoint/credentials are configured; the original development dashboard is not overwritten.
