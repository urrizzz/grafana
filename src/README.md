# Interface Map (development scaffold)

Provisional plugin ID: urrizzz-interfacemap-panel. Target: Grafana 13.2.2.

This build verifies panel registration only. Router editing, traffic visualization and live data queries
are not implemented. See the repository requirements and interactive mockups for the accepted design.
A Grafana Cloud account is not needed for local development. Signing and publication are not configured.

Source and documentation: https://github.com/urrizzz/grafana
